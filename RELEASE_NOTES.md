# Naivka 2.29.2

- Добавлен импорт Xray JSON-подписок: один профиль, массив профилей или отдельный outbound. Поддерживаются VLESS, Trojan и Shadowsocks; JSON также может быть упакован в Base64.
- Сохраняются поддерживаемые параметры TLS/Reality, WebSocket, gRPC, HTTPUpgrade и VLESS xHTTP. Неподдерживаемые варианты, цепочки прокси и параметры защиты не подменяются упрощёнными настройками: профиль отмечается как пропущенный.
- Из JSON берутся только серверы. Чужие DNS, маршруты и локальные входы не заменяют настройки Naivka. При ошибках обновления сохраняется прежний список, как и для обычных подписок.
- Сохранены запрос совместимого формата, запасной путь загрузки и сообщения об ошибках DNS/TLS/таймаута. Clash YAML, sing-box JSON и VMess пока не поддерживаются.
