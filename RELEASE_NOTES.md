# Naivka 2.31.1

- Исправлены ложные ошибки сертификата при проверке VLESS Reality до включения VPN. Обычный TLS-запрос не проверяет Reality; теперь предварительная проверка измеряет только доступность TCP-порта.
- Предварительный результат помечен `TCP` и показан нейтрально. Подсказка объясняет, что он не подтверждает работу VPN. Также уточнены подписи существующих TCP-проверок Shadowsocks и VLESS без TLS.
- После подключения кнопка «Проверить все» по-прежнему выполняет настоящий запрос через каждый сервер и показывает его ошибки. Проверка сертификатов обычных TLS-серверов и закрепление ключа сохранены.

Если подписка уже добавила серверы, но до подключения показывала «проблема с сертификатом», обновитесь, выберите сервер, подключитесь и повторите проверку. Работоспособность конкретного провайдера должна подтверждаться запросом через VPN: успешная проверка TCP этого не гарантирует.
