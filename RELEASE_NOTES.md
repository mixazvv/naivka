# Naivka 2.38.2

- Окно открывается, пока в фоне проверяется версия sing-box. Подключение и обновление ядра дожидаются результата. Повторный запуск показывает уже открытый экземпляр до чтения и расшифровки настроек.
- Списки серверов и правил копируются в памяти без промежуточного JSON. При отключённом VPN ежесекундный сбор статистики Telegram обходится без копии настроек.
- При фоновой проверке конфликтов в Windows Naivka запрашивает полный путь только у процессов, для которых он нужен, чтобы отличить своё ядро от чужого.
