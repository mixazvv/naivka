# Naivka 2.32.0

- Добавлен официальный NaïveProxy: установите компонент в «Настройки → О программе → Версии компонентов», затем переподключитесь. Существующие профили и ссылки сохраняются. До установки компонента и для UDP-over-TCP остаётся прежний sing-box.
- Добавлен Mieru: импорт `mieru://`, `mierus://` и JSON-подписок, TCP/UDP, диапазоны портов, MTU, multiplexing и handshake. Компонент устанавливается там же. Расширения traffic-pattern, upstream dialer и hashedPassword пока не поддерживаются и явно отклоняются.
- В мастере своего VPS появился Mieru: отдельная служба mita, резервная копия, сохранение пароля при повторной установке и откат при ошибке запуска. Порты — 49997 TCP/UDP. В панели хостинга их нужно разрешить отдельно.
- Mieru отображается в сведениях о VPS и управлении службами. Предварительная проверка Mieru больше не отправляет несовместимый TLS-запрос.
- Компоненты проверяются по SHA-256, секреты передаются через закрытые файлы, процессы останавливаются вместе с подключением. Правила, TUN и статистика остаются в sing-box.

Проверены официальные NaïveProxy v154.0.8037.49-5 и Mieru v3.39.0: запуск, SOCKS, остановка, импорт protobuf и передача HTTP через mita по TCP/UDP на локальном стенде. Это не проверка внешнего VPS или мобильного клиента. Новые компоненты требуют современной Windows; старые подключения legacy-сборки сохранены.
