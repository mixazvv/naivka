# Naivka 2.32.2

- В разделе «Свой сервер» добавлена кнопка «Сменить IP вручную». Можно указать прежний и новый IP своего VPS, даже если его нет в списке Naivka и протоколы устанавливались другим способом.
- Мастер находит сохранённые VPN-подключения по прежнему IP и позволяет выбрать, какие обновить. При наличии подходящих SSH-подключений панелей обновляются и они. Сам VPS автоматически в список не добавляется.
- Для ручного режима нужно сверить ключ SSH нового адреса с консолью хостинга. Ключ повторно проверяется при сохранении; изменения адресов или порта требуют новой проверки. Существующие записи VPS продолжают использовать сохранённый доверенный ключ.
- Перед сохранением создаётся резервная копия настроек. Пароли и параметры VPN сохраняются; доменные имена и серверы из подписок обновляются через DNS и источник подписки.

Проверены ручной режим без записи VPS, выбор подключений, сохранение и резервная копия, отказы при изменении проверенного адреса/ключа и интерфейс в Chromium. Реальный VPS не изменялся.
