# Naivka 2.38.1

- Если от старого обновления осталась запись без сведений о процессах, откройте Naivka, один раз перезагрузите Windows и откройте Naivka снова. После проверки она перенесёт запись и прежний исполняемый файл в папку резервных копий.
- Проверки связи выполняются по очереди. При потере интернета счётчик сбоев сервера сбрасывается. Изменение порядка сетевых адресов больше не прерывает открытые соединения.
- Подбор zapret учитывает ошибки сайтов и обрывы при получении ответа. При отмене подбора или результате хуже проверки без обхода сохраняется прежняя стратегия.
