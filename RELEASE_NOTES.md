# Naivka 2.32.1

- В разделе «Свой сервер» и в управлении VPS появилась кнопка «Сменить IP». Мастер проверяет доступность SSH и совпадение сохранённого ключа сервера, затем показывает список подключений для обновления.
- После подтверждения обновляются адрес своего VPS, выбранные VPN-подключения с прежним числовым IP и связанные SSH-подключения панелей. Пароли, SNI, сертификаты и ключи сохраняются. Доменные имена и серверы из подписок обновляются через DNS и источник подписки.
- Перед сохранением создаётся закрытая резервная копия настроек. При чужом ключе SSH, изменившихся настройках или включённом VPN операция отменяется. Активные SSH-сеансы к прежнему адресу закрываются.
- Исправлены ссылки для друзей после переноса: явно переданный адрес имеет приоритет над старым адресом в файле VPS.
- Добавлены подсказки для восстановления сети через консоль Fornex. Сетевые интерфейсы Linux и DNS-записи хостинга мастер автоматически не меняет.

Проверены сценарии сохранения, резервной копии, ошибок и выбора подключений, а также интерфейс в Chromium. Реальный VPS пользователя не изменялся.
