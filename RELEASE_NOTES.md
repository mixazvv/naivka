# Naivka 2.27.0

- Котёнок: прятки за карточками и охота за огоньком, реакции с искоркой и запиской, танец после стабильной сессии. Игры завершаются по Esc, вводу, модальному окну, ошибке подключения и отключению эффектов.
- VPS: автообновление раз в 30 секунд по явному включению в открытой панели, до 60 замеров в памяти, график CPU, скорость сети с проверкой перезагрузки/смены интерфейсов, swap, inode и PSI. Автоопрос останавливается при скрытии окна, ошибке и необходимости повторного входа SSH.
- Аудит VPS: SSH keyboard-interactive/PAM/ключи/пустые пароли/MaxAuthTries/X11 и Match для текущего SSH-сеанса; firewalld/nftables/iptables, дополнительные службы, владельцы/права/ACL известных конфигураций и сроки сертификатов по фиксированным путям. Все команды только читают данные; неизвестное значение не считается успехом. Локальные порты не доказывают доступность из интернета. Обновления ОС проверяются по существующему кэшу APT на Debian/Ubuntu.
- Диагностика: прямой DNS UDP и DoT через выделенный loopback-вход ядра, local через резолвер ОС, покрытие маршрутов IPv6 TUN и наблюдение за более специфичными публичными исключениями. Изменения стабильных атрибутов таблицы маршрутов делают план переключения устаревшим. Прямые пробы запрещены при Kill Switch; отсутствие обнаруженных исключений не доказывает отсутствие утечек.
- Обновления: выбор любой опубликованной стабильной версии с подписанным архивом своей платформы, постраничный каталог, обязательные подпись и SHA-256. Перед заменой сохраняются EXE и зашифрованные настройки в version-backups. При понижении версии автоподключение отключается; ранние версии проверяются по PID, токену и версии локального API. При отказе запуска восстанавливаются EXE и исходные настройки. Резервные копии сохраняются для ручного полного возврата: остановите Naivka и восстановите оба файла из одной копии под тем же пользователем Windows. Старые версии могут не сохранять новые настройки; проверка запуска не заменяет проверку реального VPN/TUN.
