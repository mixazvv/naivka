# Naivka 2.32.4

- Исправлена установка Mieru на VPS: предварительная проверка теперь использует отдельный временный процесс и закрытый локальный сокет. Раньше команда проверки требовала уже работающей службы и могла остановить первую установку или обратиться к другой установленной службе Mieru.
- Установка считается успешной только при состоянии `RUNNING`. Состояние `IDLE` больше не принимается за работающий VPN; при неудаче восстанавливается прежняя установка.
- Проверены повторная установка с сохранением пароля, откат, отклонение неверной конфигурации и очистка временных файлов. Проверка конфигурации выполнена с официальным mita 3.39.0, передача HTTP — через официальный клиент по TCP и UDP на локальном стенде.

Чтобы исправить ранее неудачную установку, после обновления повторите установку с выбранным Mieru. Само обновление Naivka не меняет VPS. Для подключения на компьютере нужен компонент Mieru в настройках; файрвол хостинга должен разрешать порт 49997 TCP/UDP.

Проверки на конкретном VPS, телефоне и в Windows TUN в этот выпуск не входят.
