# Naivka 2.37.1

После обычного запуска и перед установкой следующей версии Naivka проверяет следы предыдущего обновления. Если подтверждены принадлежность операции, завершение процессов и готовность приложения, файлы восстановления вместе с прежним исполняемым файлом переносятся в version-backups. Активные и неопознанные операции сохраняются для отдельной проверки в настройках обновления. Постоянная плашка восстановления убрана с главного экрана.
