# Naivka 2.35.0

- В «Серверах» появилась сортировка по пингу в обе стороны и по имени. Непроверенные серверы, ошибки и незавершённые проверки при сортировке по пингу остаются в конце; равные значения сохраняют порядок строк.
- Добавлены фильтры «Избранное», «С ответом», протокол, счётчик найденных серверов и сброс фильтров. Клавиша `/` переводит фокус в поиск, Esc очищает запрос.
- Кнопка ⇄ в строке добавляет сервер в сравнение: до трёх серверов, протокол, пинг с видом замера, страна и явная кнопка выбора. Открытие сравнения не переключает подключение; при ошибке выбора прежний сервер сохраняется.
- Выбранная сортировка сохраняется в настройках и не перезапускает VPN. Ручной порядок не перезаписывается сортировкой; для перетаскивания выберите «Мой порядок». Обновление пинга сохраняет фокус на строке или кнопке.

Чтобы включить сортировку, откройте «Серверы» → «Сортировка» → «Пинг: быстрые первыми». «Проверить все» обновит измерения. TCP, TLS и запрос через сервер измеряют разные этапы; один пинг не определяет скорость и надёжность VPN.

Оформление сохранено. Проверены сортировка, фильтры, сравнение, отмена неудачного выбора, сохранение настроек, темы и окна 320–1280 px, а также сборки Windows.
