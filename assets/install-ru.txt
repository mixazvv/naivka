КАК УСТАНОВИТЬ NAIVKA

1. Распакуйте этот архив целиком в удобную папку, например на рабочий стол
   (правой кнопкой по архиву -> «Извлечь всё»). Из архива не запускайте:
   настройки не сохранятся.

2. Запустите Naivka.exe (для Windows 7/8 - Naivka-win7-64.exe,
   на 32-битной системе - Naivka-win7-32.exe).
   Если Windows покажет «Система Windows защитила ваш компьютер» -
   нажмите «Подробнее» -> «Выполнить в любом случае».

3. Откроется подсказка «Как пользоваться». Коротко:
   - «Серверы» -> «Вставить ссылки» -> вставьте ссылку на сервер, которую вам дали;
   - нажмите большую кнопку на главном экране - когда написано «Подключено», всё работает;
   - YouTube и Discord без сервера: «Обход» -> включите zapret (Windows спросит разрешение - «Да»).
   Подсказка всегда открывается кнопкой «Как пользоваться» внизу меню.

4. Не запускайте вместе с Naivka другие VPN (Karing, Hiddify, v2rayN, Happ, AmneziaVPN и т. п.):
   они мешают друг другу.

ОБНОВЛЕНИЕ
Когда выйдет новая версия, на главном экране Naivka появится кнопка «Обновить».
Нажмите её - программа обновится и перезапустится сама, настройки и серверы сохранятся.
Если обновить так не получилось - скачайте новый архив со страницы
https://github.com/mixazvv/naivka/releases/latest и распакуйте поверх старой папки.

Если что-то не работает: «Сводка» -> «Журнал» -> «Собрать отчёт»
и отправьте файл автору (кнопка «Обратная связь», Telegram @mixazvv).
