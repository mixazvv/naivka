# Проверка Naivka 2.32.2 — 11 ноября 2026

Проверена версия 9372cda61d498975d7f6cc347b490e234b670f24.
Рабочая среда Linux; Windows проверена кросс-компиляцией amd64/arm64 и go vet.

Успешно выполнены:

- Полный `go test -race -count=1 ./...` с официальными sing-box 1.14.4,
  NaïveProxy v154.0.8037.49-5 и Mieru/mita v3.39.0. Проверены конфигурации,
  локальные SOCKS-входы, остановка процессов, импорт protobuf и реальная передача
  HTTP через Mieru/mita по TCP и UDP на loopback.
- Linux/Windows go vet, сборки Windows amd64/arm64, синтаксис серверных shell-скриптов.
- Изолированная проверка установщика Mieru: повторная установка, сохранение пароля,
  откат, отказ от неподтверждённого архива и очистка временных файлов.
- Четыре модели JS: питомец, VPS, оценки серверов, геометрия ветвей.
- Девять браузерных проверок Chromium: ветви, питомец без сети, схемы,
  транзакции диагностики, выбор версий, карточки настроек, экраны настроек,
  смена IP и компактный рабочий экран.

Обнаружены проблемы проверок, а не воспроизведённые ошибки приложения:
старый тест ветвей ожидал продолжение Telegram до Интернета; три браузерных теста
не учитывали CHROMIUM_PATH. Исправлены ожидания терминальной ветви и выбор браузера.
Исправленные проверки прошли. Проверка живых ветвей добавлена в CI.
Производственный код и версия приложения не менялись.

Это не проверка реального Windows TUN, системного прокси/драйвера WinDivert,
провайдера интернета пользователя, его подписок, внешнего VPS или телефона.
На этих устройствах ничего не запускалось и не изменялось. Успешные тесты не
гарантируют отсутствие ошибок во всех возможных конфигурациях.
