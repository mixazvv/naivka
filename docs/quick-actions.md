# Быстрые действия

## Ветви и «Сейчас»

Нажатие на сайт или программу открывает карточку: скорость, трафик за сеанс,
наблюдаемые маршруты и снимок соединений. «Соединения» раскрываются отдельно;
«Обновить данные» повторяет запрос. Фонового опроса карточки нет.
Скорость и объём берутся из последней статистики Naivka; список соединений —
из API ядра. Если программа не определена ядром, такие соединения не приписываются
выбранному процессу. Сайты сопоставляются по домену и его поддоменам.

Кнопки маршрута вызывают существующее сохранение правил. При ошибке прежние
правила возвращаются. Существующие соединения могут сохранять старый маршрут.
Перетаскивание на ветвь остаётся доступным.

## Меню сервера

Правая кнопка, кнопка «⋯», Shift+F10 или клавиша контекстного меню открывают
одинаковые действия. Стрелки, Home/End перемещают фокус, Esc закрывает меню.
Открытие меню само по себе не выбирает сервер. «Подключить» сначала сохраняет
настройки и выбирает сервер; при ошибке выбора подключение не запускается.
В режиме «Только zapret» сначала нужно вручную выбрать режим с сервером.

Доступны проверка пинга, избранное, переименование, сравнение, копирование ссылки
и подробности. Названия серверов подписки задаёт подписка, переименование для них
недоступно. Скопированная ссылка содержит ключ подключения.

## События

«Сводка → Журнал» показывает до 60 последних событий за время работы процесса.
Есть поиск и фильтр по типу. Подробности раскрываются отдельно. Технический журнал,
копирование, очистка окна и сбор отчёта сохранены в нижнем раскрывающемся блоке.
История не сохраняется на диск.

Подписки добавляют события только после успешного сохранения транзакции:
добавление, обновление со счётчиками, удаление, сохранённая ошибка автообновления.
Предпросмотр не считается обновлением. URL, имена профилей и ключи подписки в новые
события не включаются. Номер подписки соответствует её месту в списке на момент события.
