# Ручная проверка самообновления на Windows

Черновик PR не следует считать проверенным обновлением на Windows по одним
Linux-тестам. Нужны отдельные временные папки и тестовые подписанные релизы;
рабочие настройки и настоящие VPN-серверы не используются.

Проверить Windows 10/11 amd64, при наличии arm64; Windows 7/8 amd64 и 386
на сборке Go 1.20.14. Отдельно проверить установленный и портативный режимы,
переименованный EXE, пути с пробелами/кириллицей, обычные и повышенные права.

| Сценарий | Ожидание |
|---|---|
| Обновление в отключённом состоянии, AutoConnect включён | Новая копия остаётся отключённой |
| Обновление подключённого клиента | Подключение только после commit и при сохранённом намерении |
| Disconnect во время загрузки/подготовки/ready | Нет позднего переподключения новой или откатившейся копии |
| Выход во время подготовки или в кандидате | Возврат старого EXE без повторного открытия приложения |
| Новый EXE не запускается, сразу падает или зависает | Откат и понятный результат, backup не удалён раньше времени |
| Неверные версия/PID/токен callback | Готовность не принимается |
| Новый EXE отвечает ready, затем падает до commit | Возврат старой версии |
| EXE/backup/debug удерживаются антивирусом | Ошибка не скрыта, доступная копия не уничтожена |
| Нельзя переименовать файл при rollback | Фиксируется ошибка, автоматическая очистка не удаляет backup |
| Нельзя запустить восстановленную версию | Старый файл восстановлен; повторный запуск вручную |
| Резко завершён исходный процесс | Неполная запись не даёт разрешения на переподключение |
| Helper не получил EOF (процесс завис при выходе) | Новая копия не запускается параллельно |
| Отключение/выход после commit | Обычный lifecycle; старый helper больше не меняет системный прокси |
| Первая установка новой версии старым updater 2.24.1 | Явно отделить старый протокол от нового |

Готовность проверяется до автоподключения: она не доказывает доступность
интернета, работу TUN/DNS, отсутствие утечек и полную загрузку WebView2.
Эти проверки выполняются отдельно. Откат настроек Windows/серверов не выполняется
этим протоколом. Сохранять безопасные журналы без токенов и приватных конфигураций.
