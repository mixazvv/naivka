# Список серверов

В разделе «Серверы» выберите порядок:

- «Мой порядок»: сохранённый порядок с избранными выше. Здесь доступно перетаскивание.
- «Пинг: быстрые первыми» или «Пинг: медленные первыми»: сортировка положительных завершённых замеров; без ответа и без замера — в конце.
- «По имени»: естественный порядок названий, например Server 2 перед Server 10.

Сортировка сохраняется после перезапуска приложения и не меняет ручную последовательность, выбранный сервер или конфигурацию VPN. Пинг берётся из тех же измерений, которые видны в строках. Для обновления используйте «Проверить все».

Фильтры «Избранное», «С ответом» и «Протокол» работают вместе с поиском. «С ответом» означает положительный замер, включая TCP/TLS; это не подтверждение работы всего VPN. Сброс очищает фильтры и поиск, сохраняя выбранную сортировку. Если последний сервер какого-либо протокола исчезает, соответствующий фильтр сбрасывается, чтобы не оставлять пустой скрытый фильтр. Поиск и фильтры живут до выхода из программы.

`/` переводит фокус в поиск, если вы не печатаете в другом поле. Esc в непустом поиске очищает запрос, сохраняя раздел открытым. Пустой поиск оставляет обычное поведение Esc.

Для сравнения нажимайте ⇄ рядом с «Подробнее» у нужных серверов. После выбора появится кнопка «Сравнить (N/3)». Можно сравнить два или три профиля; пароли и ключи в таблицу не выводятся. «Обновить данные» читает уже имеющиеся замеры и не запускает новую проверку. Выбор сервера в таблице — явное действие, которое применяется так же, как нажатие строки в основном списке. При отказе прежний выбор восстанавливается. Удалённые серверы убираются из набора сравнения.

На узком экране таблица прокручивается внутри диалога. Вид замера указан рядом со временем: сравнивайте TCP с TCP, TLS с TLS и полноценные запросы с такими же запросами.
