# Проверка серверов Reality

До включения VPN Naivka проверяет доступность TCP-порта VLESS Reality. Результат
помечен `TCP` и показан нейтральным цветом: это не проверка ключей, UUID, short ID
или передачи трафика. Обычный TLS ClientHello не аутентифицируется в Reality;
его ошибка сертификата не позволяет объявить VPN-сервер неисправным.

После запуска ядра кнопка «Проверить все» делает полноценный запрос к TestURL
через каждый сервер. Ошибки этого запроса сохраняются: успешная проверка порта
их не заменяет. Для обычных TLS-серверов проверка сертификата до подключения
остаётся включённой; закрепление ключа также сохраняется.

## Сравнение с Koala Clash

[Koala Clash](https://github.com/coolcoala/koala-clash) использует Mihomo,
Naivka — sing-box, а для транспорта xHTTP — вспомогательный Xray. Поэтому
одинаковый список серверов сам по себе не доказывает одинаковой совместимости.
Koala скачивает удалённый профиль с собственным User-Agent и заголовками
устройства. Переключение Naivka на этот User-Agent не исправляет проверку Reality
и может изменить формат ответа провайдера на Clash YAML.

В [Mihomo](https://github.com/MetaCubeX/mihomo/blob/Meta/component/tls/reality.go)
есть отдельный параметр поддержки X25519MLKEM768. В upstream sing-box есть
[отчёт о несовместимости Reality с некоторыми новыми Xray-серверами](https://github.com/SagerNet/sing-box/issues/4520).
Это возможная причина ошибки уже при подключении, но не установленная причина
ошибки конкретного провайдера. Для такого вывода нужен результат запроса через
запущенное ядро и его журнал; список серверов или предварительная проверка TCP
недостаточны. Отключать проверку сертификатов для обхода ошибки не следует.

Приватные ссылки, UUID и пароли подписок не нужны в публичном отчёте об ошибке.

## Ошибка `unknown uTLS fingerprint: hellofirefox_120`

Это ошибка проверки локального конфига до запуска VPN. Xray принимает подробное
имя `hellofirefox_120`, а sing-box принимает имя пресета `firefox`. В sing-box
1.14.4 используется metacubex/utls v1.8.7, где `HelloFirefox_Auto` соответствует
`HelloFirefox_120`.

Начиная с 2.31.2 при генерации конфига sing-box Naivka преобразует
`hellofirefox_120`, `firefox120`, `hellofirefox_auto` в `firefox`, а известные имена
`Hello…_Auto` — в соответствующие браузерные пресеты. Обычные имена пресетов
принимаются без учёта регистра и пробелов по краям. Неизвестные и другие
фиксированные версии не подменяются Chrome или случайным профилем.

Исходный fingerprint в сохранённых серверах, экспорте и конфиге вспомогательного
Xray сохраняется. Повторный импорт подписки не требуется. Аутентификация Reality,
UUID, SNI, short ID и проверка сертификатов не меняются. Это устраняет указанную
ошибку запуска конфига, но само по себе не подтверждает доступность провайдера.

Источники: [пресеты sing-box 1.14.4](https://github.com/SagerNet/sing-box/blob/v1.14.4/common/tls/utls_client.go),
[uTLS v1.8.7](https://github.com/MetaCubeX/utls/blob/v1.8.7/u_common.go),
[имена профилей Xray](https://github.com/XTLS/Xray-core/blob/main/transport/internet/tls/tls.go).
