# Naivka

Личный клиент NaiveProxy и VLESS+Reality для Windows. Работает поверх официального
[sing-box](https://github.com/SagerNet/sing-box) (нужна версия 1.14 или новее); настройки,
маршруты, интерфейс и автоматика — свои.

## Что умеет

- **Протоколы:** Naive (HTTP/2 и HTTP/3) и VLESS+Reality. Автовыбор сам переключается между
  серверами и протоколами, если текущий перестал отвечать.
- **Маршруты:** «Россия напрямую», «Только заблокированное», «Всё через сервер» на списках
  блокировок runetfreedom и гео-базах SagerNet. Свои правила по домену, IP и программе;
  вставка целыми списками, импорт и экспорт, счётчики срабатываний.
- **Надёжность:** защита от утечек (если ядро упало, трафик не уходит напрямую), сторож
  соединения (после сна, смены сети и обрывов переподключает, при необходимости перезапускает ядро).
- **Окно и трей:** своё окно на WebView2 (тёмный заголовок, запоминает размер, закрывается в трей),
  меню в трее с выбором сервера, уведомления Windows, автозапуск.
- **Обзор:** схема «через сервер / напрямую» с реальной скоростью, график, активные сайты,
  сводка сеанса, задержка за час, лента событий, IP и страна «как вас видят сайты».
- **Диагностика:** список соединений с правилом, журнал, «Проверить сайт» — заблокирован ли сайт,
  открывается ли через сервер и по какому правилу идёт сейчас.
- **Телефон:** QR-код любого сервера и профиль для приложения sing-box на iPhone/Android
  с теми же серверами и правилами.
- **Обход без сервера:** встроенные [zapret](https://github.com/Flowseal/zapret-discord-youtube)
  (YouTube, Discord и ваши сайты — напрямую с обходом DPI) и [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)
  (Telegram Desktop без сервера). Naivka скачивает их из релизов Flowseal, обновляет и запускает сама.
- **Безопасность:** пароли в настройках зашифрованы средствами Windows (DPAPI); в режиме TUN
  ядро лежит в Program Files, куда обычные программы писать не могут.

## Выпуск новой версии (обновления у людей)

Раздавайте людям только сборки, сделанные утилитой выпуска: в них вшиты номер версии, ваш репозиторий
и открытый ключ, и такие Naivka обновляются сами. Сборки из `build.bat` — для разработки, без обновлений.

    go run ./cmd/release -repo ИМЯ/naivka -version v1.0.0   (первый раз)
    go run ./cmd/release -version v1.0.1                    (дальше)

Утилита собирает Naivka для Windows 10/11 (и 7/8, если задана переменная `GO120` с папкой Go 1.20),
скачивает свежий sing-box, собирает архивы для людей, считает контрольные суммы и подписывает их
ключом `keys/release.key` (создаётся при первом запуске). Всё нужное ложится в `dist/<версия>` —
загрузите эти файлы в релиз на GitHub с тегом версии. С `-publish` утилита опубликует релиз сама
через GitHub CLI (`gh auth login` один раз). Список изменений берётся из `CHANGES.md`.

Naivka раз в 12 часов проверяет последний релиз и предлагает обновиться («Настройки» → «О программе»).
Перед установкой она проверяет подпись ключом, вшитым при сборке: подменённый на GitHub файл
не установится. Номер версии записан внутри подписанного `SHA256SUMS` (строка `# naivka v1.0.1`),
поэтому старый подписанный релиз нельзя выложить под новым номером. Релизы, собранные утилитой
до появления этой строки, новые Naivka не примут — выпускайте обновления свежей утилитой. Ключ `keys/release.key` храните в надёжном месте и никому не отдавайте:
потеряете — старые сборки не примут новые обновления; утечёт — обновление можно будет подделать.

## Сборка

Все зависимости лежат в папке `vendor`, интернет для сборки не нужен.

| Команда | Что получится |
|---|---|
| `build.bat` | `Naivka.exe` для Windows 10/11, 64 бита. Нужен Go 1.24+ |
| `build.bat debug` | то же с консолью — если что-то падает на старте |
| `build.bat win7` | `Naivka-win7.exe` и `Naivka-win7-32.exe` для Windows 7/8. Нужен Go 1.20.x, путь в переменной `GO120` |

Тесты: `go test .` (с `SINGBOX=путь\к\sing-box.exe` ещё и проверка конфигов настоящим ядром).

## Первый запуск

1. «Настройки» → «Скачать ядро» (в портативной сборке ядро уже лежит в `Naivka-data\core`).
2. «Серверы» → «Добавить сервер» или «Вставить ссылки»: `naive+https://…`, `naive+quic://…`, `vless://…`.
3. «Обзор» → «Подключить».

Закрытие окна убирает Naivka в трей. Полный выход — меню в трее или «Настройки» → «Выйти».

## Обход без сервера (раздел «Обход»)

**zapret** (Flowseal, на основе zapret от bol-van). Naivka скачивает релиз, читает стратегии прямо
из его bat-файлов (новые стратегии из обновлений подхватываются сами) и запускает `winws.exe` скрыто.

- «Подобрать автоматически» перебирает все стратегии и проверяет адреса из `utils\targets.txt`.
  В результатах видно, какие адреса не открылись у каждой стратегии, — в том числе ваши сайты
  из правил «Через zapret» (их можно добавить прямо в разделе, блок «Что проверять»).
- «Проверить вручную» запускает стратегии по очереди (сначала лучшие по автоподбору), а вы сами
  смотрите, идёт ли видео, работает ли голос в Discord и открываются ли нужные сайты, и жмёте
  «Работает» или «Следующая». Пока идёт проверка, сайты zapret идут напрямую; «Закончить без выбора»
  возвращает всё как было.
- Сайты из списков Flowseal и правила «Через zapret» идут напрямую, мимо сервера.
- Раз в 3 минуты Naivka проверяет, справляется ли zapret. Если нет — с «подстраховкой сервером»
  эти сайты временно идут через сервер, а когда обход снова работает — обратно.
- Адреса ваших серверов всегда исключаются из обработки zapret.
- Нужны права администратора (драйвер WinDivert). Антивирусы могут ругаться на WinDivert.
- Если уже стоит zapret как служба (`service.bat` → Install Service), Naivka предупредит — удалите службу.
- Только Windows 10/11: на Windows 7 нужен другой драйвер WinDivert.

**tg-ws-proxy** (Flowseal). Naivka скачивает сборку под вашу Windows, пишет ей настройки
(порт, ключ; её собственные обновления и автозапуск отключены — этим управляет Naivka) и запускает
в портативном режиме. Кнопка «Подключить Telegram» открывает ссылку `tg://proxy` в Telegram Desktop.
У tg-ws-proxy свой значок в трее и окно настроек. В режиме TUN её соединения идут напрямую.

Проверка обновлений ядра, zapret и tg-ws-proxy — раз в 12 часов (отключается в настройках);
установка новой версии — только по кнопке. Предыдущая версия zapret остаётся рядом.
Скачанные ядро, zapret, tg-ws-proxy и Xray сверяются с контрольной суммой, которую GitHub хранит
для каждого файла релиза: не совпала — установка отменяется. Для старых релизов GitHub суммы не знает,
тогда файл ставится как раньше (только по HTTPS), а в журнале появляется запись об этом.

## Запасная подписка для белых списков

«Серверы» → «Запасная подписка» — [zieng2/wl](https://github.com/zieng2/wl), общедоступные серверы VLESS
для работы при белых списках. Naivka скачивает её (GitHub, Codeberg, GitLab, при ограничениях —
Mos.Hub и GitVerse), обновляет раз в час, отбрасывает российские серверы (через них заблокированное
не открывается) и держит как группу «Белые списки». Если сторож дважды подряд не достучался через ваши
серверы, Naivka переходит на подписку и каждые 2 минуты проверяет свои — как только они ответят,
возвращается. Серверы чужие: HTTPS они не читают, но видят, куда вы ходите.
Список серверов подписки виден в её карточке, любой можно закрепить.
Серверы на транспорте xHTTP sing-box не умеет — для них Naivka ставит рядом ядро Xray (кнопкой,
из официальных релизов XTLS, есть сборки и для Windows 7). Xray открывает для каждого такого сервера
локальный вход, а sing-box шлёт туда трафик как в обычный сервер: правила, статистика и автовыбор
остаются в sing-box. Свои серверы xHTTP (ссылкой vless://…type=xhttp) работают так же.

## Ещё

- **UDP через VLESS** («Правила» → «Особые случаи»): голос Discord и игры. Naive передаёт только TCP,
  поэтому UDP, который должен идти через сервер, уходит в ваш Reality или в подписку. Только в режиме TUN.
- **Блокировка рекламы и трекеров** — список geosite category-ads-all для sing-box: баннеры,
  счётчики, рекламные сети. Видеорекламу YouTube так не убрать: она приходит с тех же серверов
  и в том же потоке, что и само видео. Для неё нужен блокировщик в браузере (uBlock Origin).
- **Twitch без рекламы** («Правила» → «Особые случаи»). Twitch вставляет рекламу прямо
  в плейлист трансляции и решает это по стране, откуда плейлист запросили. Naivka отправляет
  только запросы плейлистов (`usher.ttvnw.net` и video-weaver) через прокси проекта
  [TTV LOL PRO](https://github.com/younesaassila/ttv-lol-pro) в стране без рекламы; само видео
  идёт как обычно. Соединение до Twitch зашифровано насквозь, прокси видит только адрес сайта.
  Убирает рекламу в трансляциях, но не в записях и не баннеры. Работает в любом режиме и в
  профиле для телефона. Если прокси проекта перестанут работать, трансляции не откроются — тогда выключите.
- **Раздача** («Настройки») — телевизор, приставка, другой компьютер используют Naivka как прокси
  (HTTP/SOCKS5) с паролем или без; подключения не из домашней сети отклоняются.
  Кнопка «Разрешить в брандмауэре» добавляет правило для частных сетей.
- **Выбор программ** для правил — из запущенных и выходивших в сеть.
- **Тест скорости** («Диагностика» → «Скорость») — задержка и скорость напрямую и через каждый сервер.

## Windows 7

Отдельная сборка: окно открывается в браузере (Chrome/Edge 109 или браузер по умолчанию),
трей и все функции на месте. Naive на Windows 7 не работает — движок Chromium перестал её
поддерживать, и у sing-box для Windows 7 нет Naive. Используйте серверы VLESS+Reality:
скрипт `server/add-reality.sh` добавляет Reality на сервер с Naive, ничего в нём не ломая.

## Портативный режим

Если рядом с exe лежит `portable.txt`, все данные хранятся в `Naivka-data` рядом с программой.
Пароли в этом режиме не шифруются (иначе не откроются на другом компьютере).

## Где что лежит

Обычно `%APPDATA%\Naivka` (портативно — `Naivka-data`):

| Файл | Что это |
|---|---|
| `settings.json` | настройки и серверы; пароли и UUID — `dpapi:…` |
| `addons\` | zapret и tg-ws-proxy (с правами администратора — `Program Files\Naivka`) |
| `core\` | sing-box.exe и libcronet.dll (в режиме TUN — `Program Files\Naivka\core`) |
| `run\` | последний конфиг sing-box и его кэш |
| `webview\` | данные окна WebView2 |
| `naivka.log` | журнал самой Naivka |
| `proxy-backup.json` | исходные настройки прокси Windows, пока Naivka их подменяет |

## Как это устроено

- **Системный прокси:** Naivka прописывает `127.0.0.1:2080` в настройки Windows и возвращает
  прежние при отключении. На случай сбоя в `RunOnce` записана команда восстановления.
- **Защита от утечек:** при падении ядра прокси Windows не возвращается — трафик упирается
  в закрытый порт, пока ядро не поднимется. В TUN ядро просто быстро перезапускается.
- **Сторож:** раз в 20 секунд запрос к адресу проверки строго через сервер (через служебный
  вход sing-box). Две неудачи — закрыть зависшие соединения, четыре — перезапустить ядро
  (не чаще 5 раз за 10 минут). Сон и смена сети тоже закрывают старые соединения.
- **IP и страна:** служебные входы sing-box отправляют проверку строго через сервер или строго
  напрямую, независимо от правил. Данные — ipwho.is и ipinfo.io по HTTPS, последний запасной — ip-api.com (только HTTP).
- **Профиль для телефона** раздаётся по домашней сети одноразовой ссылкой: 10 минут
  и не больше трёх скачиваний.
- **Интерфейс** — локальная страница на 127.0.0.1 со случайным портом; каждый запрос требует
  случайный ключ, запросы с чужим Host отклоняются.
