# Проверка живых ветвей

`node tests/branches.browser.cjs` запускает браузерные проверки схемы без VPN-сервера.
Нужны Playwright (доступный через Node.js) и Chromium. Можно указать путь к браузеру
в `CHROMIUM_PATH`; иначе используется `/usr/bin/chromium` или браузер Playwright.

Проверяются направления загрузки и отдачи, сохранение/отказ/отмена перетаскивания,
попадание ветвей в круглые узлы и общий Интернет, перенос листьев приложений, восстановление связи, reduced motion, раскладка в узком окне,
кнопка скрытых сервисов и повторное создание схемы.
`TREE_SCREENSHOTS=/путь` сохраняет пример на тестовых данных.
