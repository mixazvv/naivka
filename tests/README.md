# Проверка живых ветвей

`node tests/branches.browser.cjs` запускает браузерные проверки схемы без VPN-сервера.
Нужны Playwright (доступный через Node.js) и Chromium. Можно указать путь к браузеру
в `CHROMIUM_PATH`; иначе используется `/usr/bin/chromium` или браузер Playwright.

Проверяются направления загрузки и отдачи, сохранение/отказ/отмена перетаскивания,
попадание ветвей в круглые узлы и общий Интернет, перенос листьев приложений, восстановление связи, reduced motion, раскладка в узком окне,
компактные размеры меток, отсутствие пересечений маршрутов и наложений подписей,
кнопка скрытых сервисов и повторное создание схемы.
`TREE_SCREENSHOTS=/путь` сохраняет пример на тестовых данных.

# Проверка экранов настроек

`node tests/settings.browser.cjs` проверяет настоящие формы на локальных тестовых
данных, без подключения VPN и скачивания компонентов. Требования к Playwright и
Chromium те же, что выше.

Проверяются все категории, вкладки и страницы на четырёх размерах окна (включая
600×480 со строкой заголовка Windows): отсутствие прокрутки и обрезанных параметров,
поиск на русском и английском, сохранение переключателей, дополнительные поля DNS,
редактор своей темы, справка, большие динамические блоки и отключение наблюдателей
при выходе. Дополнительно проверяются одинаковые размеры кнопок и полей в разных
темах, выравнивание радиопунктов и справки, непрозрачность панели в Mica, формы
серверов и правил, а также масштаб 200%.
Для темы «Никогда не проси об этом» проверяются новое название на двух языках,
сохранение прежнего ключа темы, reduced motion, главный экран со схемой ветвей
и выбранная карточка сервера.
У «Пикселей» дополнительно проверяются сохранение выбора, загрузка локальной сетки,
порядок и выравнивание узлов схемы, узел прямого маршрута и доступность узлов с клавиатуры.
`SETTINGS_SCREENSHOTS=/путь` сохраняет снимки интерфейса.

# Проверка талисмана

`node tests/pet.browser.cjs` проверяет опору кадров после коррекции масштаба,
зеркальное отражение, замену обрезанных поз, моргание без смены персонажа,
дыхание без изменения палитры, изменение reduced motion во время прогулки,
отмену отложенных жестов и повторное включение котёнка.
`PET_SCREENSHOTS=/путь` сохраняет кадры на тёмном и светлом фоне.

`python3 tests/pet-atlas-audit.py` проверяет все 468 записей атласа и актуальность
коэффициентов цвета/масштаба. Нужен Pillow. После замены исходных рисунков
`python3 tests/pet-atlas-audit.py --write` пересчитывает только метаданные в
`web/pet-atlas.js`; исходный WebP не изменяется. Масштаб ограничен ±10%,
цвет выравнивается по среднему тону шерсти сидящего кота; глаза и уши
не используются как образец цвета. Опора лап и подвешенного кота сохраняется.

# Управление эффектами и диагностика

`node tests/experience.browser.cjs` проверяет события без повторов, общую политику
reduced motion, управление эффектами и локальное определение времени суток/сезона.
`node tests/repair.browser.cjs` проверяет запуск/отмену диагностики, неопределённые
результаты и остановку опроса после удаления экрана. Оба используют локальный API
без VPN и внешних сервисов; требования к Chromium и Playwright такие же, как выше.

# Привычки и игры котёнка

`node tests/pet-mind.cjs` — детерминированная симуляция усталости/отдыха,
любимых поверхностей, ограниченной памяти, редких событий, сохранения и паузы.
Playwright не требуется; тест запускается в CI.

`node tests/pet-behavior.browser.cjs` — Chromium-проверки явных игр, ввода в формы,
приоритета диалогов/сетевых ошибок, тайм-аута, reduced motion, общего отключения
эффектов, сохранения памяти и повторного mount/unmount. Требования к браузеру
такие же, как у остальных browser-тестов. Настоящий VPN не используется.


`node tests/vps-ui.cjs` — модель контроллера окна VPS без браузера и сети:
явный запуск, запрос авторизации, защита от двойного щелчка, закрытие окна,
неизвестные значения и ограничение истории. `go test -race -mod=vendor -run '^TestVPS' ./...`
проверяет серверную фильтрацию, лимит вывода, отмену и авторизацию API без SSH.
Эти проверки не заменяют проверку окна на Windows и совместимости с реальным Linux VPS.


VPS-фикстуры также проверяют кэш APT на Debian/Ubuntu без `apt update`/установки,
отсутствие индексов и ошибки формата/команд, а также TCP/UDP, пустой список,
дубликаты и усечение до 128 привязок. В UI проверяются предупреждение о возрасте
индексов, ограничения нулевого результата и различие локальных/внешних портов.

`go test -race -mod=vendor -run '^Test(ServerScores|ServerChoice|ServerScoreTick|ServerFailback)' ./...`
проверяет оценку качества серверов, гистерезис, карантин, свежесть, ручной приоритет,
отмену selector HTTP при Disconnect и сохранение резерва при ошибке возврата.
Используются fake RoundTripper и фиксированные часы, без сокетов и VPN-серверов.
`node tests/server-scores.cjs` проверяет окно результатов без браузера: честные
подписи HTTP/ICMP/неизвестной скорости, явное чтение API и игнорирование позднего
ответа после закрытия. Смена сервера на настоящем Windows VPN остаётся ручной проверкой.

Для исправлений котёнка, компоновки и мастера 2.26.0:

- `go test -race -mod=vendor -run '^Test(Repair|HomeLayout|UnknownHomeLayout)' ./...`
  — транзакции/отмена/откат/идемпотентность/планы, DNS-wire, таблица маршрутов и сетка.
- `node tests/pet-offline.browser.cjs` — захват/потеря указателя, Settings drawer,
  смена опор/вкладок, игры/модальные окна и remount, без HTTP listener.
- `node tests/layout-diagrams.browser.cjs` — координаты/высоты, узлы серверов,
  внешние drop-мишени, сохранение/отклонение правил, reduced motion и teardown.
- `node tests/repair-transaction.browser.cjs` — настоящий UI с локальным API fixture:
  подтверждение, проверка результата, откат, отмена и устаревшие планы. VPN не запускается.

`ui-regressions` в GitHub Actions устанавливает закреплённый Playwright и Chromium.
Локальный Chromium в managed sandbox может завершаться на setsockopt до создания
страницы: тогда браузерная проверка выполняется в CI. Нельзя считать fake HTTP
доказательством отсутствия утечек или проверки настоящего Windows TUN.


Для 2.27.0: `go test -race -mod=vendor -run '^Test(Version|RepairDNS|RepairRoute|VPS)' ./...`.
`TestVersionHistoricalRunner` запускает настоящий дочерний тестовый процесс с локальным
API вместо старого VPN-клиента: ready/exit/hang/чужой PID/версия/ошибка запуска,
старый cleanup `.old`, восстановление EXE и исходных настроек без reconnect.
`node tests/version-picker.browser.cjs` проверяет реальный выбор версии, недоступные
архивы, пагинацию, сохранение настроек перед установкой и показ ошибки подписи.
Модель VPS дополнена остановкой auto-refresh/потерей SSH без запроса пароля,
а также расчётом скорости и отбрасыванием reboot/сброса счётчиков/смены интерфейсов.

`python3 tests/historical-signatures.py` проверяет закрепление 37 ранних релизов,
отказ при смене asset ID/размера/digest, усечённом/изменённом скачивании,
несогласованности исходных сумм и архивов, а также реальную Ed25519 подпись OpenSSL.
Не требует сети, GitHub-токена или настоящего release-ключа.


`node tests/check-cards.browser.cjs` использует настоящий `check()` и все CSS
приложения в порядке index.html, без запуска VPN и изменения настроек компьютера.
Проверяет основной Flow, gold, blocks и светлую custom-палитру на 320/480/900/1440 px:
боковой отступ, отсутствие пересечений/горизонтальной прокрутки, сетку настроек,
переключение подписью и Space, сохранение значения, disabled/indeterminate,
видимый фокус, forced-colors и независимую кнопку «подробнее».
В CI артефакт `checkbox-cards` содержит изображения широкого и узкого окна;
локально их можно сохранить через `CONTROL_SCREENSHOTS=/путь`.
